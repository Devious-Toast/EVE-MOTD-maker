# EVE Online MOTD Maker

A lightweight, browser-based editor for creating Message of the Day (MOTD) HTML
for EVE Online. It runs locally and does not require an account, server, or
dependencies.

## Use

Open `index.html` in a modern browser. Enter a title and message, select text to
apply formatting with the toolbar, then copy the generated HTML fragment. The
preview updates as you edit. The exported fragment contains the title, supported
text formatting, and safe `https://` or `mailto:` links.
